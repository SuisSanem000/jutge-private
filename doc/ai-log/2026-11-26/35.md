## Summary

## Root Causes & Fixes

1. **CSS `[hidden]` overridden by `.btn`:**
   - `button.btn, a.btn, label.btn { display: inline-flex; }` overrode the HTML `hidden` attribute.
   - Because of that, **Rebuild PDF**, **`jtk make`**, and **`jtk lint`** stayed visible in Static Pages mode (where clicking **Rebuild PDF** did nothing), and **Open PDF** stayed visible when a problem had no prebuilt PDF (keeping the previous problem's `sum-evens.pbm` `href`).
   - Added `[hidden] { display: none !important; }` to CSS, explicitly hid server-only buttons in `renderToolbar()` whenever `state.mode !== 'server' || p.localFiles`, and reset `openLink.href = pdfUrl || '#'` when `pdfUrl` is missing.
2. **Opening a `.pbm` folder replaced all previously opened problems:**
   - Updated `ingestPbmEntries()` to merge newly opened `.pbm` problems into `state.problems` by `id` (revoking old `blob:` URLs only if replacing the same `id`) instead of overwriting `state.problems`, so previously opened problems and the built-in demo stay in the sidebar.
3. **Fallback PDF filenames:**
   - Added fallback matching in `ingestPbmEntries()` for `problem.pdf` / `statement.pdf` in addition to `problem.<lang>.pdf`.

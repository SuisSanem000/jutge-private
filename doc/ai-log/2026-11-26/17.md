## Why GitHub Pages Works on `jutge-private` but Not `jutge-org/problem-editor`

- **`SuisSanem000/jutge-private` is `PUBLIC`** (`isPrivate: false` verified via `gh repo view`), so GitHub Pages is enabled and free.
- **`jutge-org/problem-editor` is `PRIVATE`** (`isPrivate: true` verified via `gh repo view`), and the `jutge-org` organization plan returned HTTP `422`: `"Your current plan does not support GitHub Pages for this repository."`
- GitHub Pages on `jutge-org/problem-editor` will only activate if that repository is made `PUBLIC` or the `jutge-org` organization upgrades to a paid plan (GitHub Team/Enterprise).

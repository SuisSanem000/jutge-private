## Changes Made

1. **Removed folder permission error popup:**
   - Updated `#openLocalPbmBtn` so `AbortError` and `NotAllowedError` return silently without an `alert(...)`, and other picker errors fall back to `#localPbmPicker`.
2. **Persist opened `.pbm` problems across refresh (`localStorage`):**
   - Added `saveLocalProblemsToStorage()` and `loadLocalProblemsFromStorage()` (`pedit_saved_local_problems_v1`) so local `.pbm` files (`localFiles`, metadata, languages) are restored automatically on page refresh (and unbuilt `.tex` problems re-compile their PDF in-browser on selection).
3. **Clear button (`#clearLocalPbmBtn`):**
   - Added a **Clear** button next to **Open `.pbm` from PC** (visible whenever local problems are loaded) that clears `localStorage`, revokes `blob:` URLs, and resets the list back to the built-in problems.

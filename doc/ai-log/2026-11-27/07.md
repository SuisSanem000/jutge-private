# Folder Permission Prompt in Browser (`showDirectoryPicker` vs Drag & Drop)

## Summary

Chrome's security sandbox requires a `"View files"` permission dialog whenever a web button calls `showDirectoryPicker()`, and an `"Upload files"` dialog for `<input webkitdirectory>`. **Drag & drop** (`webkitGetAsEntry`) is the only browser way to open a `.pbm` folder with **zero** permission or upload prompts.

## Why Chrome Asks for Permission

- `window.showDirectoryPicker({ mode: 'read' })` (used by **Open `.pbm` from PC**) is Chrome's read-only File System Access API; Chrome always shows `"Let site view files?"` once per folder selection.
- Dropping a `.pbm` folder directly onto the sidebar (`dropZone`) bypasses both prompts completely while keeping everything 100% in browser memory.

# Why Chrome Shows "Allow this site to view and copy files?"

## Table of Contents

- [Summary](#summary)
- [How to Open Folders Without Any Prompt](#how-to-open-folders-without-any-prompt)

## Summary

The **"Allow this site to view and copy files?"** popup is **Chrome's built-in security sandbox dialog** for `window.showDirectoryPicker()`, not an application error. Websites cannot disable or bypass Chrome's native folder-permission prompt when a button requests folder access.

## How to Open Folders Without Any Prompt

1. **Drag & drop** `monedes.pbm` (or a folder of `.pbm` problems) from Finder directly onto the left sidebar (`Opened folder` area) — Chrome opens dropped folders with **zero** permission or upload prompts.
2. **Run locally:** `bun run src/index.ts viewer --dir .. --port 3456` opens all `.pbm` folders on `http://localhost:3456` with zero browser prompts.

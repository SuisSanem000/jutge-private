\Problem{Sum of Even Numbers}
\Statement
Given an integer $N$ followed by $N$ integers, output the sum of the even integers among them.
\Input
The first line contains an integer $N$ $(1 \leq N \leq 1000)$. The second line contains $N$ integers $x_i$ $(-1000 \leq x_i \leq 1000)$.
\Output
Output a single integer: the sum of the even integers.
\SampleOneCol
\begin{verbatim}
5
1 2 3 4 5
6
\end{verbatim}
\begin{verbatim}
3
1 2 3
2
\end{verbatim}
\begin{verbatim}
4
-4 -3 2 -6
-10
\end{verbatim}
\begin{verbatim}
4
-4 -3 2 -6
-10
\end{verbatim}

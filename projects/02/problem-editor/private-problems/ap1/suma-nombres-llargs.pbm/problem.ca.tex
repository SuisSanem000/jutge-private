\Problem{Suma de nombres llargs}


\Statement

Feu un programa que llegeixi parells de nombres naturals i escrigui la seva suma en una base donada.
La base es troba entre 2 i 36 i els dígits dels nombres són 0, 1, 2, ..., 9, A, B, C, ..., Z.

\medskip

Com que els naturals que es consideren en aquest problema poden ser
molt grans (milers de dígits), cal guardar-los en variables de tipus
\textbf{string}. El programa principal ja se us dóna implementat; no el toqueu:

\begin{lstlisting}
    int main() {
        int b;
        string x, y;
        while (cin >> b >> x >> y) {
            cout << suma(b, x, y) << endl;
        }
    }
\end{lstlisting}


Implementeu doncs la funció
\begin{lstlisting}
    string suma(int b, string x, string y);
\end{lstlisting}

que, donades dues cadenes de caràcters $x$ i $y$ que representen dos naturals
en base $b$, i un natural $b$ amb $2\le b\le 36$,
retorna una cadena de caràcters $z$ que representa la suma
de $x$ i $y$, també en base $b$.

\medskip

Podeu suposar que ni $x$ ni $y$ tenen zeros a l'esquerra.

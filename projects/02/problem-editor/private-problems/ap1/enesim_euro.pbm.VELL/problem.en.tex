\Problem{The n-th euro}


\Statement

Imagine we have a business that manages invoices and we are interested in knowing what the n-th euro is spent on each invoice. For example, if we have an invoice with three elements that cost 100 euros each, we can say that the 150th euro has been spent on the second element of the invoice.

Write a program that reads invoices and indicates for each invoice what the n-th euro has been spent on.

\Input

The input consists of two numbers $k$ and $n$ followed by $k$ invoices with a variable number of elements. Invoices are separated by '---'.

\Output

For each invoice you must write what the n-th euro has been spent on following the pattern we see in the public test cases.

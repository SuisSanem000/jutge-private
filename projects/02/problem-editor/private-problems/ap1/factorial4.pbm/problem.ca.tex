\Problem{Factorial recursiu}

\Statement

Escriviu una funció recursiva que, donat un natural $n$, retorni el seu factorial @n@$!$.

\Interface
\begin{tabular}{rl}
Python &
\begin{lstlisting}[language=Python]
    factorial(n: int) -> int
\end{lstlisting}
\end{tabular}

\Precondition

Es compleix $0\le n \le 1000$.

\ObservationNoMain

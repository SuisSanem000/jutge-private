\Problem{Països i províncies (1) en Python}

\Statement

La ONU vol guardar informació sobre l'organització dels seus països membres
i de les províncies que aquests contenen, juntament amb el seu PIB (producte
interior brut). 

\medskip

La informació sobre una província determinada es guarda a la classe següent:

\lstset{language=Python}
\begin{lstlisting}
    @dataclass
    class Provincia:
        nom: str
        capital: str
        habitants: int
        area: int
        pib: float
\end{lstlisting}


La informació sobre un pais determinat es guarda a la classe següent:

\begin{lstlisting}
    @dataclass
    class Pais:
        nom: str
        capital: str
        provincies: list[Provincia]
\end{lstlisting}

La informació sobre tots els paisos es guarda en un vector de paisos:


\begin{lstlisting}
    Paisos: TypeAlias = list[Pais]
\end{lstlisting}

Utilitzant les definicions anteriors, implementeu la funció

\begin{lstlisting}
    def pib(paisos: Paisos, inicial: str, densitat: float) -> float: ...
\end{lstlisting}

que retorni la suma dels productes interiors bruts de totes les províncies
amb densitat estrictament superior a @densitat@
de tots els paisos en @paisos@ que comencin per la lletra @inicial@.

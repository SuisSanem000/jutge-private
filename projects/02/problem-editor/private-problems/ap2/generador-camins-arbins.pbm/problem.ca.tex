\Problem{Generador de camins en un arbre binari}

\UsePython

\Statement

Donat un arbre binari d'enters, es vol generar tots els camins possibles des de l'arrel fins a les fulles (de l'esquerra cap a la dreta). Cada camí es representa com una llista d'enters corresponent als valors dels nodes que el formen.

\medskip

Per a fer-ho, escriu un generador que implementi la següent capçalera:

\begin{lstlisting}
    def genera_camins(arbre: Arbre) -> Iterator[list[int]]
\end{lstlisting}

on \textit{Arbre} és un arbre binari definit per:

\begin{lstlisting}
    @dataclass
    class Node:
        x: int
        fe: Arbre
        fd: Arbre

    Arbre: TypeAlias = Node | None
\end{lstlisting}

\medskip

El programa principal i l'esquelet del programa ja es dónen implementats, descarrega'l! L'entrada consisteix en la descripció d'arbres binari en preordre, on les fulles estan indicades amb el valor $-1$. La sortida és el conjunt de tots els camins des de l'arrel fins a alguna fulla, representats com a llistes d'enters en ordre d'esquerra a dreta i obtinguts amb el generador.

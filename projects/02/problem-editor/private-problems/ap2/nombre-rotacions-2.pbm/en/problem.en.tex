
\Problem{Number of rotations (2)}

\Statement

Given a (non empty) circularly sorted vector of integers, find the number of
times the vector is rotated. Assume that there are no duplicates in the vector
and the rotation is in anti-clockwise direction.

\medskip

For instance,
\begin{itemize*}
\item {} [8, 9, 10, 2, 5, 6] is rotated three times,
\item {} [9, 10, 2, 5, 6, 8] is rotated two times,
\item {} [4, 0, 1, 2, 3] is rotated one time, and
\item {} [2, 5, 8, 9, 12] is rotated zero times.
\end{itemize*}

\medskip

Solve this problem \emph{with recursion}
in \emph{logarithmic time}, using this header in C++:

\begin{lstlisting}[language=C++,morekeywords={string,vector}]
    int number_of_rotations (const vector<int>& v);
\end{lstlisting}

or this header in Python:

\begin{lstlisting}[language=Python]
    number_of_rotations(v: list[int]) -> int
\end{lstlisting}

\medskip

Write the specification of the recursive function that you will need to write
in a comment at the beginning of such function.

\ObservationNoMain

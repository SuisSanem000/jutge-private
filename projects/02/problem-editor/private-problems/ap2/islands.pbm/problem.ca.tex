
\Problem{Illes}

\Statement

Donades matrius de caràcters on els punts representen aigua
i les os representen terra, compteu quantes illes hi ha.
Per exemple, la matriu

\bigskip

\texttt{\hspace*{6.5cm}O.O...OOOO\\
\hspace*{6.5cm}..O.O.O...\\
\hspace*{6.5cm}OOOO..O...\\
\hspace*{6.5cm}O..O.O....\\
\hspace*{6.5cm}OOOO...OOO\\
\hspace*{6.5cm}.O.O..OOOO\\
\hspace*{6.5cm}.....OOO..\\
\hspace*{6.5cm}...O..OOO.\\
\hspace*{6.5cm}O.O.O..O..\\
\hspace*{6.5cm}OOOO...OOO\\
}

representa el mapa

\FigureC{width=5cm}{imatge1}

on hi ha cinc illes:

\FigureC{width=5cm}{imatge2}

\Input

L'entrada és una seqüència de matrius.
Cada matriu comença amb el nombre de files $n > 0$
i de columnes $m > 0$ del mapa.
Segueixen $n$ files amb $m$ caràcters cadascuna.
Un \q{.} indica una posició amb aigua,
i una \q{O} indica una posició amb terra.


\Output

Per a cada mapa, cal escriure el seu nombre d'illes.

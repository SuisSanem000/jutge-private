
\Problem{Trees --- Height}

%a l'enunciat original apareix profunditat, pero la definicio que es dona correspon a height segons wikipedia
%"The height of a node is the length of the longest downward path to a leaf from that node. The height of the root is the height of the tree."
%http://en.wikipedia.org/wiki/Tree_(data_structure)


\Statement

Write a program that reads the shape of various binary trees,
and prints the height of each one.
We define the height of a tree
as the maximal number of nodes
of the paths that go from the root to each leaf
(or zero, if the tree is empty).



\Input

Input starts with $m$, the number of trees that must be treated.
The description of the $m$~trees follow
as explained at problem \Link{P98436}, with an exception:
All the values are 0,
because the content of the nodes here is not important.



\Output

Your program must print the height of each given tree.

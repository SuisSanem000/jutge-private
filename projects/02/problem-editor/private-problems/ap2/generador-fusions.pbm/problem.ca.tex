\Problem{Generadors de fusions}

\UsePython

\Statement

Escriviu una funció 

\begin{lstlisting}
def fusio_generadors(generadors: list[Iterator[int]]) -> Iterator[int]:
\end{lstlisting}\vspace*{-6mm}    

que, donada una llista de generadors infinits que generen naturals en ordre creixent, retorni un generador que contingui tots els elements de tots els generadors en ordre creixent i sense repetir elements.

\medskip

Per exemple, si els generadors són [1, 2, 3, 5, ...] i [2, 2, 4, 6, ...], el generador de fusions hauria de retornar [1, 2, 3, 4, 5, 6, ...]. Per a [2, 4, 6, 8, ...], [3, 6, 9, 12, ...] i [5, 10, 15, 20, ...], el generador de fusions hauria de retornar [2, 3, 5, 6, 8, 9, ...].

\medskip

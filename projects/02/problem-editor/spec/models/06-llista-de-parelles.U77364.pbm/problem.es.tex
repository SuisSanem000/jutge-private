
\Problem{Lista de Parejas}

\Statement

Haz una función con cabecera:

\begin{verbatim}
list<pair<string, int>> all_pairs(map<string, int>& M);
\end{verbatim}

que devuelve una lista de todas las parejas que hay en \verb|M|.

\Input

La función recibe un \verb|map|, posiblemente vacío.

\Output

La función devuelve una lista de las parejas que hay en el 
\verb|map|, en el orden de la llave (en este caso, 
\verb|string|).

\Observation

\textbf{No} hagas el programa principal. El Jutge utiliza uno 
que lee unos datos y llena el \verb|map|, luego llama a 
\verb|all_pairs| para obtener la lista y finalmente la 
escribe.

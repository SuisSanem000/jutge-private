pedit CLI

AI-assisted Jutge problem-editor CLI built in Bun + TypeScript around unmodified jtk (4.4.50).

Download & Run

Download pedit CLI (pedit.tar.gz)

tar -xzf pedit.tar.gz
cd pedit
bun install
bun run src/index.ts --help

How It Works

  • Unmodified jtk backend: Runs jtk make, jtk make pdf, jtk lint, jtk verify, and jtk clean with structured --json output.
  • OpenRouter SDK: Uses @openrouter/sdk with selectable low-cost models (default google/gemma-4-26b-a4b-it:free or openai/gpt-4o-mini), reading OPENROUTER_API_KEY (or ANTHROPIC_AUTH_TOKEN when routed via OpenRouter).
  • Hidden master prompts & skills: Preloads spec/constitucio.md, spec/problema-jutge.md, and skills/problemes-jutge/SKILL.md so user prompts stay short.
  • Closed-loop verification: Blocks LLM writes to *.cor / problem.yml, runs generate.ts + jtk make all + PDF render + jtk lint, and auto-retries up to 2 times on errors.

Commands

pedit list [--dir ..] [--json]
pedit status <problem.pbm> [--json]
pedit show <problem.pbm> [file]
pedit build <problem.pbm> [--json]
pedit pdf <problem.pbm> [--json]
pedit lint <problem.pbm> [--json]
pedit verify <problem.pbm>
pedit meta <problem.pbm> --lang en --title "..." --author "..." --email "..."
pedit handler <problem.pbm> --compilers G++17
pedit models | pedit presets
pedit create <dir.pbm> "<problem idea>" [--model openai/gpt-4o-mini]
pedit edit <dir.pbm> ["<instruction>"] [--preset add-edge-tests]
pedit chat <dir.pbm>

pedit CLI

AI-assisted Jutge problem-editor CLI built around unmodified jtk (4.4.50).

Download

Download pedit bundle (pedit.tar.gz)

Bundle is packaged automatically by GitHub Actions once projects/02/problem-editor/pedit/ is added.

How It Works

  • Unmodified jtk backend: Calls jtk make, jtk make pdf, jtk lint, and jtk verify deterministically.
  • OpenRouter SDK: Lets you choose models (e.g. DeepSeek v4) for conversational edits, with future routing to Jutge's API.
  • Hidden master prompts: Loads spec/ and skills/ automatically so prompts stay focused only on the problem idea or edit request.
  • Closed-loop verification: Re-runs jtk after edits so errors self-correct.

Planned Commands

pedit list
pedit status <problem.pbm>
pedit build <problem.pbm> --json
pedit edit <problem.pbm> "add edge case tests for empty input"

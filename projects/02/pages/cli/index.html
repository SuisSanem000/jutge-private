pedit CLI

AI-assisted Jutge problem-editor CLI built in Bun + TypeScript around unmodified jtk (4.4.50).

1. Download & Install

Download pedit CLI (pedit.tar.gz)

tar -xzf pedit.tar.gz
cd pedit
bun install
export OPENROUTER_API_KEY="your-key"
bun run src/index.ts --help

2. How to Work With pedit

# Inspect problems in a directory
bun run src/index.ts list --dir .. --json
bun run src/index.ts status ../generated-demo/sum-evens.pbm --json

# Deterministic jtk wrappers (run unmodified jtk under the hood)
bun run src/index.ts build ../generated-demo/sum-evens.pbm --json
bun run src/index.ts pdf ../generated-demo/sum-evens.pbm --json
bun run src/index.ts lint ../generated-demo/sum-evens.pbm --json

# Deterministic metadata & handler updates
bun run src/index.ts meta ../generated-demo/sum-evens.pbm --lang en --title "New Title"

# AI-assisted creation & editing (default model: openai/gpt-4o-mini)
bun run src/index.ts create ./my-problem.pbm "Problem idea..."
bun run src/index.ts edit ./my-problem.pbm --preset add-edge-tests
bun run src/index.ts chat ./my-problem.pbm

3. How pedit Differs from jtk

jtk is kept completely unchanged as the deterministic build, test, PDF, lint, and upload engine. pedit sits on top of jtk to handle AI-assisted authoring and editing:

Dimensionjtk (Existing)pedit (New CLI)
RoleDeterministic build, test, PDF, upload engineAI-assisted problem editor & workflow wrapper
LLM BackendFixed Jutge API (openai/gpt-6-luna)OpenRouter SDK (default openai/gpt-4o-mini; selectable models; Jutge API later)
InteractionOne-shot jtk generateConversational edit / chat + suggested presets
Prompts & RulesHardcoded in CLIHidden master prompts loading spec/ & skills/ automatically
VerificationManual (jtk make / lint run separately)Closed-loop (runs jtk automatically & self-corrects; never writes *.cor)

## 2. Phase 1: What You Studied & Mastered

- **Strict Directory Anatomy:** A problem is a self-contained `.pbm` folder containing:
  - `handler.yml` (rules, limits, compiler modes: `G++17` vs `PRO2`).
  - `problem.en.yml` (metadata: title, author, email).
  - `problem.en.tex` (LaTeX statement with preconditions and sample tables).
  - `solution.cc` (golden optimal solution).
  - `generate.ts` (testcase generator script).
  - `scores.yml` (grading rubric).
- **The Golden Rule of `.cor` Files:** Expected output files (`*.cor`) must **never** be written by humans and **never** generated by LLMs; they must be produced deterministically by compiling and executing `solution.cc` via `jtk make`.
- **C++17 Pedagogical Constitution:**
  - Forbidden: `std::unordered_map`, lambdas, `enum class`, `std::variant`, `constexpr`, destructuring.
  - Mandated: Early termination on searches, simple and readable code, standard containers (`std::vector`, `std::map`, `std::set`, `std::string`).
- **Complete English Translation:** You established a pure English specification suite in `doc/problem-editor-en-translate-20261111/` so that no language barriers exist.

## 4. The Big Technical Finding: Why `jtk` Must Be Rebuilt

Executing Phase 2 revealed the critical engineering bottleneck that prevents building Phase 3 (the Next.js SaaS Web Editor):

1. **Current `jtk` is an Interactive Terminal CLI:**
   - It is coupled with `@inquirer/prompts` and terminal formatting (`chalk`).
   - It cannot be imported as a headless TypeScript library (`import { compile, verify } from '@jutge/core'`).
2. **Lack of Machine-Readable Diagnostics (`--json`):**
   - Current `jtk` prints human-readable strings to `stdout`.
   - When a test generator or compiler throws an error, an AI agent cannot parse structured line numbers, error types, or exit codes. Automated self-correction becomes brittle.
3. **The Proposal for Your 4-Month Internship:**
   - Rebuilding `jtk` into a decoupled headless engine (`@jutge/core`) with a machine-readable CLI/MCP contract is the **exact foundation needed to power the Phase 3 web editor**.
   - You have formulated a 4-month architecture proposal ([`PROPOSAL-PRESENTATION-20261112.md`](../03-for-meeting-tomorrow/PROPOSAL-PRESENTATION-20261112.md)) to deliver this engine.

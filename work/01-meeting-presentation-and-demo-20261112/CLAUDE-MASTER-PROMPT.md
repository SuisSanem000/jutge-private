Title: Dominant Mountain Peaks
Author: Simin Shoeibi
Email: simin.shoeibi@estudiantat.upc.edu
Language: en

Description:
Given a sequence of integers representing the elevations of mountain peaks from left to right, a peak is called "dominant" if it is strictly higher than every peak that appears to its right in the sequence. The last peak in the sequence is always dominant by definition.

Constraints:
- Input contains multiple test cases until EOF.
- Each test case starts with integer N (1 <= N <= 100,000), followed by N integer elevations.
- Elevations range: -10^9 <= E_i <= 10^9.
- Time limit: 1.0 second. Memory limit: 128 MB.

Complexity Requirements:
- Optimal (solution.cc): O(N) time and O(N) auxiliary space. Scan from right to left while maintaining the running maximum elevation, collect dominant peaks, and reverse/output them in their original left-to-right order.
- Slow Alternative (solution-slow.cc): Naive O(N^2) time. For each element, scans all subsequent elements to verify dominance. This solution must pass correctness tests, but trigger time-limit exceeded (EE) on large efficiency tests.
